# BloomWell

AI-powered maternal healthcare and emergency SOS monitoring system.

## Features
- Daily pregnancy monitoring
- AI symptom analysis
- Medication tracking
- Emergency SOS alerts
- GPS live location sharing
- Doctor & ambulance notifications
- Multi-language support

## Emergency SOS
If sudden fall or emergency movement is detected:
- Relatives are alerted
- Ambulance is contacted
- Doctor receives emergency alert
- GPS location is shared instantly

## Tech Stack
- React
- Gemini AI
- Groq
- Mistral
- NVIDIA NIM
- Ollama
- GPS Sensors
- Accelerometer Sensors
